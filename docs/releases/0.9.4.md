# 0.9.4: the HUD tells you when there is a new version

Works with the same planner as 0.9.3.

## Added

- **A new version shows on the HUD.** When a newer TT HUD is out, the banner shows a yellow
  **update** chip with its version, and the plan panel (no plan loaded) a **Download** button.
  Either opens the release page. It shows before the start and after the finish, never while
  you race. The mod asks GitHub at most once a day for all its windows together.

## Fixed

- **The update check in settings** read the first tag by name, so from version 0.10 it would have
  said v0.9.x was the newest and never offered the update. It now reads the latest release (else
  the highest version among the tags).
