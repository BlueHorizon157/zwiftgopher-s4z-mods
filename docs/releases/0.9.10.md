# 0.9.10: ready for the Sauce mod store

Works with the same planner as 0.9.9. Nothing you set up needs doing again: install it as
before, by unzipping it over the old copy in `Documents/SauceMods`. Your windows, plans and
link stay as they are.

- **Ready for the Sauce mod store.** When the mod is listed in Sauce's own mod store and you
  install it from there, Sauce keeps it up to date each time it starts. A copy from the store
  no longer checks GitHub for a newer version, and its settings page says "kept up to date by
  Sauce". A copy you unzip yourself still checks GitHub once a day and tells you when a newer
  release is out.
